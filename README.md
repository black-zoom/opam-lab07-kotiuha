## Завдання 1. Filter<T>

Критерії:
- Числа: від'ємні або нульові.


## Завдання 3. Aggregate<T, TAcc>

### Сума
- Стан: `int`
- Старт: `0`
- Крок: `state + x`

### Добуток
- Стан: `int`
- Старт: `1`
- Крок: `state * x`

### Максимум
- Стан: `int`
- Старт: `int.MinValue`
- Крок: `x > state ? x : state`

Для порожнього списку максимум не обчислюється: повертається `null` після окремої перевірки.

### Середнє арифметичне
- Стан: `(int Sum, int Count)`
- Старт: `(0, 0)`
- Крок: `(state.Sum + x, state.Count + 1)`

Сума й кількість накопичуються за один прохід. Для порожнього списку середнє дорівнює `NaN`.

```
Максимум: 1
Сума: 5
Добуток: 0
Середнє: 0.25
```

## Завдання 5. Захоплення змінних

### Зміна змінної після створення лямбди

```
False
```

Лямбда захоплює змінну `threshold`, а не її початкове значення. Після зміни порога на `1000` перевірка `2 > threshold` повертає `false`.

### Цикл for

```
for (3): 3, 3, 3
```

Усі лямбди захоплюють одну змінну `i`. Після завершення циклу її значення дорівнює `3`.

### Цикл foreach

```
foreach (3): 0, 1, 2
```

У сучасному C# кожна ітерація `foreach` має окрему змінну ітерації, тому лямбди повертають різні значення.

### Виправлений for

```
Виправлений for (3): 0, 1, 2
```

Проблему виправлено створенням локальної копії `int copy = i` у кожній ітерації.

| Тест | Очікуваний результат |
|---|---|
| Порожній список для `Filter` і `Map` | Порожній список |
| Сума порожнього списку | `0` |
| Добуток порожнього списку | `1` |
| Максимум порожнього списку | `null` після перевірки |
| Середнє порожнього списку | `NaN` |
| Жоден елемент не відповідає критерію | Порожній список |
| Усі елементи мають однаковий ключ | Одна група |
| Список з одного елемента `7` | Усі агрегації дорівнюють `7` |

## Завдання 6. Висновки

### Порівняння з лабораторною №4

Для трьох критеріїв і трьох типів даних без узагальнення могло б знадобитися до дев'яти окремих функцій. У цій роботі використовується один `Filter<T>` і три лямбда-вирази з різними критеріями.

### Де узагальнення зайве

`GetScoreRange(int score)` виконує конкретне завдання для цілочисельного бала. Узагальнення цього методу не дає суттєвої користі, але ускладнює код.
